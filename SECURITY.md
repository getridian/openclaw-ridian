# Reporting a security issue

Use [GitHub private vulnerability reporting](https://github.com/getridian/openclaw-ridian/security/advisories/new)
for suspected security issues. Include the plugin and OpenClaw versions and
reproduction steps with synthetic data. Do not include tokens, OAuth codes,
private messages or account databases.

For setup problems and other bugs, use [Issues](https://github.com/getridian/openclaw-ridian/issues).
